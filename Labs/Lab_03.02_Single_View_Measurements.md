# Lab 3.2 Single View Measurements

In this lab you will experiment with measuring the height of an object from an image.

1. You will need to use a camera with known focal length.  You can use the same camera that you used for Lab 3.1 and reuse the focal length estimate from that lab.

2. Put your phone upright on a desk and take a picture of an object, making sure that the camera is not tilted up or down.

3. Measure the height of the camera off of the desk, the size of the object, and the distance to the object.

 4. Measure the size of the object in the image (in pixels) and the y-coordinate where it touches the desk using an image editor app or this [measurement tool](https://colab.research.google.com/github/calpoly-csc4888/CSC-4888-Labs/blob/main/Notebooks/Measurement_Tool.ipynb).

5. Making use of these measurements and your focal length estimate, estimate the distance to the object and then the height of the object.  Compare to physical measurements of the object's size and distance.
